Retail Analysis Capstone Project

Description
This project analyzes retail sales and customer data to uncover business insights such as sales trends, customer behavior, and performance patterns. It combines SQL-based querying, Python-based data cleaning and exploration, and an interactive Power BI dashboard to present findings in a clear, actionable format.

Project Files
1.retail_analysis.sql – SQL queries used to explore and analyze the retail dataset.
2.data cleaning.ipynb – Jupyter notebook covering data cleaning and preprocessing steps.
3.merged_retail_notebook.ipynb – Combined notebook with data merging, exploratory analysis, and insights.
4.excel_capstone_project.xlsx – Excel workbook with supporting analysis and visualizations.
5.capstone_final.pbix – Power BI dashboard file for interactive data visualization.

Tools & Technologies
1.SQL
2.Python (Pandas, Jupyter Notebook)
3.Microsoft Excel
4.Power BI

Installation / Requirements
1.To view/run the notebooks: Python 3.x with Jupyter Notebook and Pandas installed.
2.To view the dashboard: Microsoft Power BI Desktop.
3.To review queries: any SQL client (e.g., MySQL Workbench).

Usage
1.Clone this repository.
2.Open data cleaning.ipynb to see the raw data preparation steps.
3.Open merged_retail_notebook.ipynb for the full exploratory analysis.
4.Open capstone_final.pbix in Power BI Desktop to explore the interactive dashboard.
5.Refer to retail_analysis.sql for the underlying SQL queries used in analysis.
